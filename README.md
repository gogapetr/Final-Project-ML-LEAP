# Final-Project-ML-LEAP
A public agency wants to use survey data to flag which households are likely to be in a higher-income bracket, so that a benefit or outreach programme can be targeted. Does a simple, transparent model whose decisions can be explained to the public beat a more complex neural network that might, or might not, be more accurate?
